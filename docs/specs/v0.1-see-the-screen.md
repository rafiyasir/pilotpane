# Spec v0.1: See the screen

Covers draft specs 001 to 008 (see [roadmap](../ROADMAP.md)). Status: **built, waiting for manual test**.

## Goal

From an old laptop's browser (Chrome 109 on Windows 8), see the host's full screen live over the LAN, after typing a PIN, with nothing installed on the viewer.

## In scope

- Monorepo (pnpm workspaces, strict TypeScript, dependency policy).
- Typed protocol package with our own SHA-256 and PIN proof.
- Own HTTP server and WebSocket (RFC 6455), LAN-only listeners refreshed every 3 s.
- PIN pairing with nonce proof, lockout, resume tokens, one viewer at a time.
- Primary screen capture, WebRTC send-only, H.264 preferred, 1080p / 720p presets.
- Viewer page: PIN entry, connection states, stream view, toolbar, stats overlay, themes, auto-reconnect.
- Host: control window, full-screen PIN on start, tray menu, pause/resume, new PIN, port-busy and no-network screens, keep-awake while streaming.

## Out of scope (later versions)

Mouse and keyboard (v0.2, v0.3), low-bandwidth preset (v0.2), HTTPS and clipboard (v0.5), start on login (v0.5), host screen off (v0.6), installer/packaging.

## User flows

1. **Start**: run `pnpm start` on the host. Full-screen PIN appears with the address. The host window and tray icon appear.
2. **Pair**: open the address on the viewer, type the PIN. The PIN screen on the host closes by itself.
3. **Watch**: the host's screen fills the viewer. Move the mouse to the top for the toolbar.
4. **Drop**: unplug the cable for a few seconds. The viewer keeps the last frame, shows "Reconnecting", and resumes without the PIN.
5. **Stop**: "Disconnect" on the viewer, "Disconnect viewer" or "Pause sharing" on the host, or quit from the tray.

## Acceptance criteria

| ID | Criterion |
|---|---|
| AC-1 | `pnpm install && pnpm build && pnpm test` succeed on Windows 11 in Git Bash; all tests pass. |
| AC-2 | `pnpm start` shows a full-screen PIN (6 digits) and at least one LAN address within 5 s when a network is present. |
| AC-3 | The host listens only on private LAN addresses and 127.0.0.1 (check with `netstat -ano \| findstr 7420`: no `0.0.0.0:7420`). |
| AC-4 | Opening the address in **Chrome 109 on Windows 8** shows the PIN page with no console errors. |
| AC-5 | A wrong PIN shows "That PIN didn't match. N tries left."; 5 wrong PINs lock pairing for 60 s on both sides. |
| AC-6 | The right PIN closes the host's PIN screen and shows the host screen on the viewer within 5 s. |
| AC-7 | Stream is 1080p by default; switching to 720p in the toolbar changes the resolution in the stats overlay within 3 s. |
| AC-8 | Stats overlay toggles and shows latency (RTT), fps, bitrate, size, codec, loss. Host window shows viewer, duration and stats. |
| AC-9 | A second viewer gets "Someone else is connected" while the first one is watching. |
| AC-10 | Unplugging the network for up to 30 s: viewer shows "Reconnecting" over the last frame and resumes without the PIN. |
| AC-11 | "New PIN" on the host disconnects the viewer and asks for the new PIN. |
| AC-12 | "Pause sharing" disconnects the viewer and stops listening; "Resume sharing" brings back the PIN and address. |
| AC-13 | If port 7420 is busy, the host shows "Port 7420 is busy" with "Use port 7421", which works. |
| AC-14 | With no network, the host shows "No local network found" and recovers by itself when a cable is plugged in. |
| AC-15 | The host display does not go to sleep while a viewer is watching. |
| AC-16 | Closing the host window keeps PilotPane in the tray; double-clicking the tray icon shows the big PIN screen. |

## Manual test plan

**On the host (Victus, Git Bash):**

```bash
cd pilotpane
pnpm install
pnpm test
pnpm start
```

Allow the firewall prompt (Private, and Public if you use a direct cable). Note the address and PIN.

**On the viewer (old laptop, Chrome 109):** open `http://<address>:7420`, then walk through AC-4 to AC-16 above. For AC-3 run `netstat -ano | findstr 7420` in `cmd` on the host. For AC-13, quit PilotPane, occupy the port in another terminal with `node -e "require('http').createServer().listen(7420,'127.0.0.1')"`, then run `pnpm start` again.

**If something fails:** run `PILOTPANE_LOG=debug pnpm start` and copy the terminal output; on the viewer press F12 > Console and copy any red lines.

## Known limits

View only. Primary display only. No audio. The UAC secure desktop can't be captured. The host's own screen stays on.
